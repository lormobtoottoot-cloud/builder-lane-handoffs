# Start Here

This static portal provides:

- Spark Builder Lane for Aunt, unchanged in `spark/`.
- The canonical hosted TradeCore paper app: https://tradecore-fusion-mobile.dewytick512.chatgpt.site/

Open https://lormobtoottoot-cloud.github.io/builder-lane-handoffs/ to choose a lane.

Spark downloads contain starter files. TradeCore downloads now contain only app links and update instructions; the earlier TradeCore mock is retired.

For TradeCore changes, use the app's **Creation Space** shortcut or the **TradeCore Creation Space** conversation. Keep the same existing app URL. See `TRADECORE_UI_BUILDER_INSTRUCTIONS.md`.

This repository remains static. Do not add secrets, API keys, backend execution, terminal control, wallet movement, or real trading.
