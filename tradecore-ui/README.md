# TradeCore — canonical application

Open https://tradecore-fusion-mobile.dewytick512.chatgpt.site/

The old TradeCore UI Lane mock is retired. This folder and its download package contain only a link to the current hosted app; they are not another TradeCore implementation.

On iPhone or iPad, open the app in Safari and choose **Share → Add to Home Screen**. Keep that same URL for future updates. The trading app opens without ChatGPT login and uses simulated prices and funds.

For changes, use the app's **Creation Space** shortcut, select **TradeCore Fusion** in Sites, and choose **Edit**, or continue the **TradeCore Creation Space** conversation. Editing requires the owner account. Publish changes to the existing application; do not restart development from this retired mock.

Earlier browser/local session histories are not imported by this link. The owner retained a recoverable backup before retiring the old source.
