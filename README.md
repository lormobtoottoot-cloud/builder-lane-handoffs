## TradeCore changes

Open the current app and its **Creation Space** shortcut. Select **TradeCore Fusion** in Sites, then **Edit**, or continue the **TradeCore Creation Space** conversation. Completed changes are verified and published to the existing app URL, so Home Screen installations keep working. Editing requires the owner account; trading-app access remains login-free.

Do not restart the retired UI-only mock from this repository. The hosted app retains its own cookie-isolated cloud paper accounts; this static portal does not contain its backend, keys, or account data.
